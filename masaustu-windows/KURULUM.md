# Masaüstü Analog Saat (Windows)

Sağ üst köşede duran, pencerelerin arkasında kalan (yalnızca masaüstünde görünen) küçük analog saat.

![Önizleme](onizleme.png)

## Kurulum

1. Ücretsiz **Rainmeter** programını indirip kurun: https://www.rainmeter.net
2. Bu klasördeki **`AnalogSaat.rmskin`** dosyasına çift tıklayın ve **Install** deyin.
   Saat sağ üst köşede açılır.

**Elle kurulum (gerekirse):** `AnalogSaat` klasörünü
`Belgeler\Rainmeter\Skins\` içine kopyalayın. Rainmeter'ı açıp
**Skins → AnalogSaat → AnalogSaat.ini → Load** seçin.

## Kullanım

- Saat masaüstüne sabittir: açık pencereler onu kapatır, masaüstüne dönünce (Win+D) görünür.
- Saate **sağ tıklayarak** koyu/açık tema ve küçük/orta/büyük boyut seçebilirsiniz.
- Windows açılışında otomatik başlaması için Rainmeter'ın kendisinin açılışta çalışması yeterlidir (varsayılan olarak öyle).
